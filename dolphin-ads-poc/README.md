# Dolphin -> Meta Ads: тестовый запуск (PoC)

Запуск **только локально**, на ПК, где открыт Dolphin{anty}: Local API слушает `localhost:3001`.

## Установка

```bash
pip install requests playwright
```

`playwright install` не нужен: подключаемся к браузеру Dolphin по CDP.

## Перед запуском

1. Dolphin открыт, профиль **закрыт** (скрипт сам его запустит).
2. В профиле залогинен FB, Ads Manager открывается без чекпоинтов.
3. ID профиля: в Dolphin -> профиль -> копировать ID.
4. Если Dolphin просит авторизацию для API: панель -> API -> создать токен ->
   `export DOLPHIN_TOKEN=...` (Windows: `set DOLPHIN_TOKEN=...`).

## Шаг 1 - только чтение (dry-run)

```bash
python launch_test_ad.py --profile 123456789
```

Выведет кабинеты, их статус, валюту и страницы. Ничего не создаёт.

## Шаг 2 - создать тестовую кампанию (всё в PAUSED)

```bash
python launch_test_ad.py --profile 123456789 --create \
  --account 1234567890 --page 1122334455 \
  --image ./creative.jpg --link https://site.com \
  --budget 5 --country UA \
  --text "Текст объявления" --headline "Заголовок"
```

Создаёт: кампанию Traffic -> адсет (LINK_CLICKS, гео, 18-65) -> картинку -> креатив -> объявление.
**Ничего не включает.** Включаешь руками в Ads Manager после проверки.

## Предохранители

- `MAX_DAILY_BUDGET = 10` в коде, выше скрипт не пустит.
- Проверка `account_status == 1` перед созданием.
- Пауза 1.5 сек между запросами.
- Все запросы идут через `fetch` внутри профиля: тот же IP, прокси и отпечаток.

## Типовые ошибки

| Ошибка | Что делать |
|---|---|
| `Токен не найден` | Открой Ads Manager в профиле руками, проверь чекпоинт, увеличь `wait_for_timeout` |
| `Dolphin не запустил профиль` | Профиль уже открыт или нужен `DOLPHIN_TOKEN` |
| `Invalid parameter` на адсете | Пришли текст ошибки (`error_user_msg`), поправлю параметр |
| `code=190` | Токен протух, перезапусти скрипт |
| Версия Graph API устарела | `export GRAPH_VERSION=v24.0` |

## Риски

- Неофициальный путь: токен берётся из сессии, а не из app. Это нарушает ToS Meta.
- Тестируй на кабинете, который не жалко.
